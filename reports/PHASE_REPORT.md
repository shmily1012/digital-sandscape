新增 `resistance_solver_gpu.gd` 与 `resistance_solve.glsl`，调用可复用 GPU 排液组件求 `H v = F`。阻尼 Richardson 使用背景阻力 .04 作为预条件、松弛 .8；每次速度修正后重新计算 H(v)，以真实力残差而非递推差判定。外层上限 1–16 次修正，测试配置 8 次；最多 budget+1 次排液调用。压力未收敛时不读取旧 H 更新速度，在剩余外层调用内复用压力重试。预算用尽或非法外力时不发布候选，旧速度逐字节保留。没有 CPU 中途读回，也没有推进颗粒位置。

单粒、相切位置单粒、64² 十六粒三组，各做外力、反向外力、外层预算不足、压力预算不足、NaN、零力、恢复，共 21 情景零失败。成功速度与独立 CPU 矩阵自由求解相比，最大差 2.79e-6。另以 CPU 双精度重新计算每个接受速度的 H(v)，最大力残差 1.17e-7，小于未改变的 2e-7 验收阈值。零力输出为零。这里求得的是固定几何的自由速度，尚不包含接触反力。

初版十六粒失败；重试发现压力残差停在约 1.5e-4 的 float32 舍入量级，单纯增加重复调用没有解决。新增显式可选 backward-error 压力判据：容差为 `2e-6 + 4 eps * max_i(|rhs_i| + sum_j w_ij (|p_i| + |p_j|))`。这比原 RHS-only 判据更宽，明确只由新速度求解器启用，不宣称绝对压力残差达到 2e-6。新接受态十六粒归一化压力残差约 7.9e-4；最终速度仍经独立 CPU 力平衡 2e-7 约束。该浮点误差尺度是工程判据，不是严格误差定理，受压力零点和条件数影响，不能推广为全参数精度保证。非有限误差尺度也拒绝。

单粒三次速度修正、约 31–36 ms；十六粒五次修正、约 85 ms。均为单次 GPU 时间，不含渲染/接触/位置推进。收敛后仍预录剩余排液调用，当前严重浪费，不满足桌面摆件预算。Richardson 对所有正定 H 并不保证以此固定松弛收敛；未覆盖的高阻力条件可能正确耗尽预算，后续需改善求解与调度。

## GPU 排液幅值归一化与零输入

可复用排液组件新增 GPU 源项幅值归一化：几何核生成 Bv 后，单个有界 reduction 扫描面通量峰值 s；压力方程使用 Bv/s，求得的液流乘回 s，再计算反向力。s=0 时液流直接置零，保留背景阻力项 .04v。因此速度为零时 H 精确为零，不再残留上一轮压力容差对应的小力。只缩放求解变量，不修改颗粒位置、时间或材料状态。压力缓存现在保存归一化压力，不能作为实际物理压力直接显示。

12 组连续真实 GPU 对照零失败，新增 1e-20 倍速度冷启动、缓存后小输入、1e38 倍有限速度、巨大输入后恢复。误差按输入幅值除回再与 CPU oracle 比较，最大 1.12e-8，未用绝对 1e-7 掩盖小输入相对误差。1e-20 冷启动实际执行 39 个 V-cycle，证明没有直接把小 RHS 当作零接受；零速度 H 精确为零。预算不足和 NaN 仍拒绝且保留旧输出。

极大输入首轮失败；诊断显示几何源项、还原液流及 RHS 的中间运算会出现非有限值。对关键中间量使用 GLSL precise 保留运算次序后，1e38 倍有限输入通过。未声称适用于所有 float32 数值、极小渗透率或退化几何。拒绝/恢复检查继续保留，极大值仅为数值压力测试，不是产品速度范围。

## 持久切向接触历史：局部本构候选

本轮完整 CPU 130 项测试通过（26.446 秒），原 GPU 基线 1000 tick 零失败。新历史模型仅 CPU 局部验证，原接触多解/等价性问题尚未解决。

新增 `tangential_history.py`，独立实现二维切向弹簧/滑块：`xi_trial=xi_old+delta_s`，`xi_new=clamp(xi_trial, -mu*N/k, mu*N/k)`，`F_t=-k*xi_new`。当前法向力 N 是输入，尚未与接触/液体共同求解。切向位移采用连续输运的局部切线坐标；调用方必须使用规范接触朝向并提供接触点相对滑移（含自转时需计入自转）。本模块不实现自转或三维接触坐标输运。

历史按有序稳定整数 ID 对索引，不能使用每帧可重排的数组下标。批量更新创建候选字典，不改旧历史；重复 ID、非法力或中途失败均不提交。消失的接触移除弹簧，释放的储能单独计入损耗；重新接触从新弹簧开始。提供版本 1 JSON 可序列化的接触历史快照与恢复，测试恢复后的后续响应一致。这只是接触子状态，不是应用完整存档功能。

能量核验：输入功 `-F_t*delta_s` 减弹性能变化，等于非负塑性耗散加 `.5*k*(xi_new-xi_old)^2` 的隐式离散耗散。测试覆盖加载/静止持力/卸载反转、滑移上限、300 次变载能量平衡、接触分离、重排、快照恢复、失败保留和非法版本等七项。刚度改变必须显式处理能量，目前拒绝静默修改。

物理参考来自 LAMMPS 官方 granular 文档关于 linear_history 的方程和累积切向位移说明： https://docs.lammps.org/pair_granular.html 。没有复制 GPL 源码，未引入 LAMMPS 依赖。没有照搬其完整阻尼、滚动或三维模型。

下一步需将 `u_t + xi_old/dt + lambda_t/(k*dt)=0` 的粘着关系及滑移边界接入隐式接触求解，并让粒子状态与历史状态共同提交。仍须重跑捕获的顺序敏感网络，不能凭局部回归宣称唯一性已经解决；刚度/时间步/自转及浓相排液的物理标定仍缺失。原库仑等价性失败报告继续保留，未替换 GPU 或主应用。


## 摩擦接触顺序审计与分支重建

本轮 12 组顺序审计和两组分支重建证书检查通过；CPU 单元测试 123 项通过（26.443 秒），原 GPU 基线 1000 tick 零失败。此前接触唯一结果等价性门槛仍失败，不被这些诊断覆盖。

`friction_order_audit.py` 在同一 16 粒几何、同一完整移动率下，比较三种遍历顺序和两种松弛系数，分别运行摩擦 .5 与 0，共 12 组。有摩擦时相对原顺序最大速度差 8.07321e-4；无摩擦六组差异均小于 9e-13。所有结果独立力平衡和 Coulomb 约束检查通过。完整速度、接触法向/间隙/反力和初始颗粒已保存至 `reports/friction-order-audit.json`。额外只用对角阻力的 4/9/16 粒对照未复现明显顺序差异，说明此见证依赖摩擦与非局部响应组合，不能泛称所有接触代码错误。

`friction_branch_audit.py` 以原顺序和反序得到的开离/粘着/滑动状态重建线性分支，再求对原结果的最小范数修正。304 维系统数值秩分别为 300/299；修正前后速度变化仅约 1.2e-12，两分支速度差仍为 8.07321e-4。线性残差均约 1.73e-18，独立接触不等式/互补/摩擦耗散误差约 1e-26。它提供当前离散模型不同可行解的浮点证据，不是精确算术唯一性定理。

诊断过程曾直接求最小范数绝对解，虽然线性残差很小，却违反接触不等式（约 1e-4）。已改为从已验证可行解作小修正，并重新检查不等式；不能仅以线性系统解或矩阵秩宣称物理解。最终脚本对证书和分支差异设断言。

决策：原完整矩阵接触结果不能作为唯一物理解 oracle；保留原等价性失败，不将阈值放宽到 1e-3，不把遍历顺序当作艺术随机性。接下来需要评估带接触历史的柔顺/摩擦模型及状态保存，使解选择来自物理历史，而不是求解器偶然顺序。不能预先保证该方案唯一或适合 GPU，仍需耗散、步长和顺序测试。

## 圆形颗粒几何体积与有限步排液核验

本轮完整 CPU 测试 111 项通过（25.224 秒），GPU 基线 1000 tick 零失败；新几何模型仍为 CPU 实验。

新增 `disk_volume.py`：解析积分圆与网格单元交集，不归一化补面积；占据率超限、颗粒重叠或穿越封闭网格边界明确拒绝。实际圆盘截过每个面的长度给出固相体积通量 B，新增 `DrainageResistance(..., geometric=True)` 可选择该几何算子；旧平滑核保留作为对照。

有限步固相通量采用 x→y 和 y→x 两条坐标路径的平均，由每行/列占据量变化累加构造，满足 `phi_new-phi_old+dt*div(j_s)=0`。压力补偿通量因此能把旧液相占据量更新到 `1-phi_new`。此通量是几何输运构造，不是碰撞时真实轨迹，不能用中间路径代替接触求解。面截面积的瞬时通量另与占据率的中心差分导数比较。

新增六项测试：16/32/64 网格解析面积、占据导数与面通量、八个角度有限移动的固液平衡、接触与重叠、几何阻力耗散、正反路径与材料身份。`python experiments/deposition/geometric_drainage_cycle.py` 运行四粒 40 步，其中向下 24 步、反转 16 步；逐步保留材料与面积，最大液相占据量误差 2.48e-12。第一次运行因接触默认容差允许的微小穿透被几何检查拒绝；显式将接触容差收紧至 1e-12 后完整通过，未扩大几何容差掩盖问题。

关键未解决项：有限步几何液流与冻结阻力液流最大差 0.033564（无量纲）；因此尚不是非线性一致的液体/接触演化。需步长收敛与一致迭代再评估。几何颗粒小于单元且未切面时瞬时 B 可能为零，存在分辨率依赖；没有渗透率本构标定、气泡排除或 GPU 实现。圆形容器在这些实验里仍是封闭网格掩膜，不能冒充精确圆壁接触。

## 变分排液阻力 CPU 候选

本轮验证：完整 CPU 105 项通过（24.430 秒）；真实 GPU 原基线 1000 tick、零失败。GPU 结果只覆盖未改动的旧基线，不是新排液模型 GPU 验收。

新增 `experiments/deposition/drainage_resistance.py`。冻结当前几何，B 将粒子面积乘速度分配到面上，q 为液相体积通量。约束为 div(q+Bv)=0，封闭边界无外部面。

最小化 `0.5*v^T D v + 0.5*sum(h²*q²/m) - F^T v`，D 为正的背景颗粒阻力。先对各单位粒子速度求最小耗散排液 q，得到 Q；消去液流后 `H=D+Q^T W Q`，移动率为 `H^-1`。因为新增项是半正定 Gram 矩阵，此处无需替换移动率自响应或裁剪负特征值。已有接触求解器直接接受该移动率。

这是独立候选，不是修补后已经验证的悬浮液本构：D 代表背景阻力，并非相对采样液速的滑移阻力；粒子面积通量使用现有平滑核，并未保证局部固相体积分数不超过 1。当前没有演化孔隙率、固相占据量、气泡或壁面润滑。瞬时 div=0 不等于有限步体积输运已经守恒，不能据此替换产品求解器。

自动检查覆盖原 32² 非重叠接触反例的正功率、功率与耗散相等、移动率互易、封闭混合通量平衡、降低渗透率增加阻力，以及支撑静止/反转释放。下一步应建立 B 与固相占据量变化的一致离散，检查移动后的孔隙率与体积误差，再做多颗粒沉积和尺度收敛。当前仅 CPU，未迁移 GPU。
