# 稀相颗粒与 Darcy 载液耦合候选

## 最新：离散自响应参考修正

增加当前粒子位置的单位力响应校准：每颗粒分别沿两个坐标方向施加单位力，用同一网格、核与压力算子求出自身 2×2 迁移率块；实际速度减去该块乘以自身力，再加指定的自由滑移。其他颗粒引起的流动保留。单位力源项先归一化再求解，避免精细网格的源项尺度导致绝对残差触及浮点底限。

该方向参考 [Horwitz 与 Mani 关于未扰动流速的论文](https://arxiv.org/abs/1509.07542)及[离散 Green 函数方法](https://arxiv.org/abs/2004.08480)的建模问题说明；本项目为线性 Darcy 算子独立推导的校准实现，不声称复现其完整流体算法。

CPU 构造完整修正迁移率并以 Cholesky 检查正定性：移除自身块后若任意力组合可能产生负耗散，拒绝该配置。已验证重叠的密集反例被拒绝；这只是稀相适用性检查，不能替代颗粒接触。

结果：偏格心颗粒在 16²/32²/64² 上的指定斜向滑移 `(0.0111966362, 0.0149288483)` 均恢复，CPU 最大速度误差 1.72e-13；相邻颗粒的作用仍在。完整 76 项 CPU 测试、六组 GPU 单步对照及旧 GPU 守恒回归通过。GPU 最大位置差 4.89e-8，拒绝场景字节不变。

**重要范围**：GPU 对照使用 CPU 在当前初始位置校准后上传的矩阵；还没有实时 GPU 自响应求解或快速查表。CPU 每次推进会重新校准，成本是 2N 次压力求解与矩阵检查。不得在粒子移动后继续使用旧位置矩阵并声称已验证，也不得将全域自身响应扣除解释为正确的近壁润滑/阻力；目前恢复的是指定的自由颗粒极限。下一步需要可扩展的校准方法和移动状态测试，仍未接入主两相窗口。

证据：`grain-self-response.json`、`grain-coupling-validation.json`。以下为早期候选与缺陷历史。

新增 CPU/GPU 双向力传递候选：三类不可变材料粒子，以紧支撑面权重向载液分配浸没重量，求解封闭压力，再用同一组权重采样流速，叠加相对滑移推进粒子。GPU 每个粒子/面/格独占写入，阶段间 barrier；无浮点原子。候选位置越界或压力失败时，整批粒子保持原字节状态。

## 实现验证通过，但物理模型尚不合格

- 新增四项 CPU 检查：分配力守恒、粒子/网格离散功率一致、压力投影耗散、反转方向/材料身份、越界拒绝。完整 CPU 套件 73 项通过。
- 五组 GPU 对照：向下/斜向/向上/压力预算不足/越界；最大位置差 3.53e-8，源项差 6.10e-8。拒绝工况粒子逐字节保持不变，材料与半径/阻力/密度字段始终保留。
- 旧 GPU 1000 tick 守恒回归通过。修复了 GDScript 保留方法命名和类型推断错误，并移除了触发编译器诊断的动态向量取分量，最终日志无该诊断。

## 发现的物理缺陷：自身扰动回采样

单粒子位于圆心，r=0.012、drag=0.04、density=2.65；滑移速度固定为 0.0186611，但相同粒子在不同网格下得到：

| 网格 | 采样自身流速 | 有效沉降速度 |
|---|---:|---:|
| 16² | 0.0096039 | 0.0282650 |
| 32² | 0.0403336 | 0.0589947 |
| 64² | 0.1630778 | 0.1817388 |

这不是可接受的网格收敛：当前采样包含颗粒自身施力产生的扰动，再叠加自由滑移，会导致随网格变化的自迁移贡献。即使力与功率传递完全一致，也不能证明正确的单颗粒终端速度。必须先引入未扰动流速/自迁移修正或重新推导有限尺寸颗粒迁移率，再接入两相实验；目前不得把此候选当作物理验收成功。

此外，这是无量纲稀相模型，没有固相体积排除、粒间接触、密集阻滞、气泡界面阻挡或沙床摩擦。触墙仅拒绝，不是碰撞解决器。O(粒数×面数) 的直接求和只用于小规模验证，尚未进行颗粒 GPU 性能标定。
