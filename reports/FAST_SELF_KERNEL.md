# 快速自响应核候选

本轮避免逐粒子求两次压力：离线生成周期 512 的离散无散投影核，保留自响应所需的 9×9×4 个系数。每个查询由当前粒子面权重计算双线性形式，并加入光滑圆域的 Neumann 边界谐函数修正。GPU 查询不需压力求解，核仅 1296 字节；它是离散算子系数，不是预生成粒子轨迹或画面。

周期离散核近似无限域响应；实际压力网格是阶梯圆边界，边界修正使用光滑圆，两者并不完全一致。CPU 仅允许均匀单位迁移率，距圆边界小于四格的查询拒绝。GPU 当前独立验证也采用单位迁移率；生产调用时必须遵守同样限制。该条件不构成全域误差保证。

## 推导约定

周期网格的面散度符号为 `D_a = 1-exp(-ik_a)`，投影符号为 `P_ab = delta_ab - conjugate(D_a)*D_b / sum(abs(D)^2)`；零频保留均匀流。粒子自响应是以相同归一化权重双侧采样 `P/h²`。

圆域边界修正来自 Neumann Green 函数的谐项 `-log(abs(1-z*conjugate(w)/R²))/(2*pi)` 的混合导数；二次项的源/目标混合导数为零。按面中心成对积分该修正，而不是只在粒子中心评价。这里修正的是当前 Darcy 模型的自响应，仍不等于真实液体中有限尺寸粒子的近壁阻力。

## 验证结果

- 对 16²、32²、64² 的四个内部位置，与精确校准比较；指定斜向力下速度误差为自由滑移速度约 0.073%–0.565%，12 点均低于本实验 1% 检查阈值。只验证这些点与一种粒子参数，不声称所有位置/参数均满足。
- GPU 12 点及近壁拒绝检查通过；每点重复 128 次查询，最大 GPU/CPU 近似矩阵差 3.47e-4。近壁返回无效，不生成伪造有效矩阵。
- RX 7900 XTX 上每组 128 同位置查询约 0.31–0.56 ms，一次未预热采样；仅查询算子，不包含粒子推进、压力或渲染，不是混合位置/大量颗粒稳定基准。
- 78 项 CPU 测试与旧 GPU 1000 tick 守恒回归通过。

## 连续轨迹与保守适用条件（后续验证）

新增 `fast_grains.py` CPU 实验。每步从当前位置重算近似自响应，整群仅一次载液压力求解；两条轨迹分别从各自上一状态推进，不逐帧用精确位置覆盖快速轨迹。

耗散门控：互易载液迁移率为半正定，若每个粒子的 `sym(I/drag - K_approx)` 正定，则全体修正迁移率的对称部分正定。代码用 2×2 最小特征值检查。这是充分而非必要条件，可能拒绝精确全矩阵校准允许的配置；它不是物理准确性的证明。原 drag=0.04 参数不能直接走此路径，实验显式采用 drag=0.01，不修改原基线参数。

只允许既定圆形、单位迁移率和内部区域；整步越出支持区或出现线性路径上的颗粒接触便拒绝，不消失、不反弹造假，也不修改输入状态。这是稀相适用边界，不是接触求解器。

实测：32²、三材料三颗粒、dt=0.02、30 步，分别经历向下、斜向与反向重力。快速路径与逐步精确校准独立演化，最大位置距离误差 7.36795e-6（坐标域宽度为 1），低于预设 1e-4 阈值。仅覆盖这条短轨迹。证据：`fast-trajectory-validation.json`。

82 项 CPU 测试通过；旧 GPU 1000 tick 守恒回归 failures=0。此次没有修改 shader，新增连续路径未做 GPU 验证，不得用旧 GPU 测试替代。


## GPU 连续推进（后续验证）

`online_grains.gd` 保留原精确校准路径，增加显式 `use_fast` 模式。快速模式由 GPU 从当前粒子位置查询核、检查充分耗散条件，再进行一次共享载液压力求解和候选推进。独立 guard pass 检查支持区域及整条线性路径的粒子接触，随后整批提交或保留；dispatch 间有 barrier。没有逐帧向 GPU 上传参考粒子位置。当前仍限制 32²、最多八粒，以实验范围为准。

真实 Vulkan 验证：30 步与 CPU 快速路径最大单坐标差 1.195e-7；材料/粒径/阻力等属性字节保持不变。冷启动预算不足、重叠接触、近壁、不满足耗散条件均保留原粒子字节；非单位迁移率在初始化时拒绝。独立自响应 shader 的 13 组验证、原精确在线路径和旧 1000 tick 守恒也通过。

此次 30 步 GPU timestamp 中位数约 4.3 ms；温启动通常两个八循环批次，冷启动与重力切换最多六批，最慢约 13.8 ms。是三粒子、局部 RD、压力/核/推进总成本，不含界面、渲染、主设备调度和桌面整机利用率；不能推算成产品功耗。CPU/GPU 测试读回仅用于验证，求解器没有内部整场 CPU 回传。

```powershell
python experiments/liquid/fast_trajectory_validation.py
python run.py fast-self
python run.py fast-grains
python run.py online-grains
```

证据：`fast-grain-fixtures.json`、`fast-grain-validation.json`。没有接入主窗口；拒绝接触只保证不错误穿透，不会产生真实沉积。下一步必须建立可持续接触/摩擦与排液耦合，不能用此稀相路径冒充密集沙床。
