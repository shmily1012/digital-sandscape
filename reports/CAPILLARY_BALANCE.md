# 毛细力与压力平衡实验（2026-10-24）

## 本轮实现

`experiments/liquid/capillary.py` 新增局部高度函数曲率估计，以及与压力使用同一面梯度/流动系数的毛细通量。平衡形式为 `q = M (sigma*kappa*grad(c) - grad(p))`。当曲率恒定时，`p = sigma*kappa*c + constant` 可以精确抵消毛细项；实际曲率误差则会产生伪流。

方法选择参考 [Popinet 2009 原始研究](https://www.sciencedirect.com/science/article/pii/S002199910900240X) 中平衡力与高度函数曲率的组合及静态液滴验证思路。这里只实现了原创简化均匀网格算例，没有复制 Gerris 代码，也没有实现论文完整求解器。

高度函数使用三列、每列十一格的积分条带，要求两端处于相反纯相、条带单调且只有一个界面。曲率仅在混合 cell 估计。七格/九格条带曾漏掉部分斜向界面；十一格解决了当前圆泡算例覆盖问题，但不是任意形状的通用保证。靠墙、薄膜、小泡及多界面可能不可解析，代码明确抛错，不用零力或任意圆拟合补洞。

这是纯两相平面曲率实验，圆泡期望压差 `sigma/R`。尚未加玻璃间隙方向曲率、接触角、液膜或三相接触线；不能把平面压差当作真实 KB 流沙画的完整压差。参数均为无量纲验证值。

## 发现与修复

最初用固定采样积分生成测试圆泡体积分数，32²→64² 时最大伪流从约 0.0048 增至 0.018。查明圆周切点附近的初始化积分误差被二阶曲率差分放大后，改为圆与单元矩形交叠面积的分段解析积分。当前最大伪流随细化下降。解析圆仅用于测试初始化，绝不在演化中重置/重画气泡。

## CPU 实测

新增 7 项 CPU 检查：圆面积、恒曲率平衡、平界面、曲率收敛、实际估计的压差/伪流收敛、不可解析几何报错和压力分解等价性。全量结果见下方最终验证记录。

`python experiments/liquid/capillary_validation.py`，R=0.2、sigma=0.01、圆心偏离网格对称位置：

| 网格 | 曲率来源 | 压差 | 最大面伪流速度 |
|---|---|---:|---:|
| 32² | 解析恒定曲率（对照） | 约 0.05 | 1.72e-12 |
| 64² | 解析恒定曲率（对照） | 约 0.05 | 1.03e-12 |
| 32² | 从相分数估计 | 0.0506391 | 0.00484151 |
| 64² | 从相分数估计 | 0.0501482 | 0.00107690 |

实际曲率的压差相对误差从约 1.28% 降至 0.296%，平均界面曲率误差从 0.06619 降至 0.01508。伪流仍非零，没有达到生产静态平衡验收。压差统计以 c>0.999 / c<0.001 分组，解析恒曲率对照的微小压差偏差包含极少量混合 cell 采样效应。

## GPU 验证边界

已有压力/面通量 GPU fixture 增加恒曲率与实际估计曲率两种 32² 毛细输入。曲率和毛细输入仍由 CPU 生成，GPU 只解压力并计算最终通量；此测试不能证明曲率估计、毛细力生成或界面时间演化已经 GPU 化。结果以 `liquid-gpu-validation.json` 为准。

首次直接求完整压力时，两组毛细输入的 GPU 散度残差约 1.62e-5 / 1.65e-5，超过原定 1e-5，测试失败。修复采用等价压力分解：选择已解析曲率的平均值 k_ref，令 `p = sigma*k_ref*c + p_residual`，GPU 求 `sigma*(kappa-k_ref)*grad(c)` 对应的剩余压力。k_ref 可取任意常数，不需要知道真实半径；恒曲率部分由基础压力精确平衡，并未删除毛细力。新增 CPU 测试证明最终通量及重构总压力与原方程一致（压力允许常数规范差）。

修复后 GPU 对比的是剩余压力及最终物理通量；中间的 pressure-correction flux 不能单独称为完整液体通量。没有放宽误差或散度阈值。曲率来源和基础压力仍由 CPU 测试夹具提供。
