# 液体压力、回流与保守输运实验（2026-10-24）

## 实现与结论

新增 `experiments/liquid/`：封闭有限体积压力投影 CPU 模型、GPU 压力迭代与面通量修正，以及 CPU 五材料漂移/回流输运。它补上了此前“液体只有阻力、没有排液约束”的缺口，但还不是完整流沙画求解器，未替换主应用。

薄腔低惯性 Darcy 近似有物理依据：深度平均压力梯度驱动流动，侧壁施加不穿透条件；气液界面还需要独立的压力跳跃条件。依据是 [Thompson 2021 原始研究](https://link.springer.com/article/10.1007/s10665-021-10146-y)，本轮阅读了模型方程和适用限制，未复制其实现。该文不是沙画标定数据；当前代码也没有实现论文中的自由界面压力跳跃。

## 离散与边界

压力位于 cell 中心，通量位于相邻 cell 的公共面。仅建立两个活动 cell 之间的面；矩形外边界及圆形 mask 边界不建立流通面，因此严格封闭。圆形当前是阶梯边界，不是精确曲线 cut-cell。

独立排液实验输入相通量 `j`，解 `div(j - M grad(p)) = 0`。`M` 是正的流动系数，面系数采用两侧调和平均。液体补偿通量为 `-M grad(p)`。CPU 使用有上限的共轭梯度迭代，按真实散度残差判定收敛；失败明确抛出，不静默宣称不可压缩。支持非均匀流动系数及相互隔离的封闭区域。

GPU 使用加权 Jacobi、两个压力 SSBO 交替读写和 dispatch barrier；面修正 shader 每 invocation 独占一个面。测试允许同步读回，主程序没有新增读回路径。当前严格对照采用 16² 的 2,048 次、32² 的 8,192 次迭代，仅用于精度验证，**不适合作为产品每帧迭代预算**。32² 最初 4,096 次的 CPU 残差为 1.0756e-7，未达到预设 1e-7，因此增加迭代，未放宽阈值。下一步应使用残差控制与更快求解方法，不能用固定高迭代掩盖性能成本。

## 五材料输运的额外假设

`transport.py` 保存液体、三种矿物和气体的体积分数。给定各相相对漂移，压力修正产生公共载体速度；每相面通量由漂移通量及按上游体积分数分配的载体通量组成。所有相的面通量之和满足投影后的体积约束。依据出流速率选择有界 CFL 子步，以成对面交换保存各材料库存。

这里的载体速度不能直接称为液体体积通量：真正液体通量还乘液体体积分数。它也不是完整双向颗粒动力学；相对沉降/浮升速度仍是规定值，没有接触力、浓度依赖阻力或固相压实。此输运模型是后续耦合底座，不能把颜色层输运视为单颗粒身份/接触已解决。

## 实测结果

- CPU 单元测试 43 项全部通过（新增压力 6 项、输运 4 项）。新检查覆盖局部/全局体积闭合、所有截面零净通量、已知压力场、变系数、反向运动、通量能量投影、断开区域、迭代失败、旋转后各材料库存、非负性及时间步收敛。
- `python run.py liquid`：Godot 4.7.2 / Vulkan / RX 7900 XTX，4 组压力及实际 GPU 面通量对照，0 failures。最大状态分量误差 9.98491e-8；最大局部散度残差 1.43052e-6。阈值分别为 2e-6 / 1e-5，详见 `liquid-gpu-validation.json`。五材料时间推进尚未移植到 GPU，不能用本项证明其 GPU 正确性。
- CPU 圆形 24² 输运：180 个子步、9 个无量纲时间单位，时间 4.5 后旋转 135°，没有重建状态。最大材料库存误差 1.38778e-17；最大局部总体积误差 1.51470e-10；最小体积分数 0。详见 `liquid-transport.json`。
- 实际计算结果图：`liquid-returnflow.png`、`liquid-transport.png`。已检查图像，气相界面明显数值扩散；不是艺术效果已达标。
