# E2 功能气泡候选实验（2026-10-24）

## 结论

已实现独立 CPU / GPU 候选模型及对照实验，尚未接入主程序，也未通过真实流沙画物理验收。动态气体夹杂可以改变颗粒释放，但这不足以证明正确重现了薄层玻璃中的气液沙相互作用。

## 实现

`experiments/bubbles/model.py` 用过阻尼圆盘表示沙粒，用面积恒定的椭圆表示气泡。浮力、阻力、接触反作用和周长能量梯度共同演化位置与形状。参数全部是无量纲实验值，不是 KB 产品的实测参数。此处三种颜色只保留材料身份，密度相同；不同矿物的真实参数尚未标定。

`step.glsl` 使用两个 SSBO 交替读写；每 invocation 只写一个物体，各步之间 barrier。数据为位置、半径、形状、种类、材料和密度。小规模全对全接触是 O(N²)，仅用于验证规则，不能直接扩展到产品粒子数。GPU 测试使用固定安全小步长；CPU 实验有自适应子步与步数上限。未测完整应用 GPU 成本。

四个对照使用相同的 30 颗沙粒：无气泡、单气泡、两个气泡、固定椭圆障碍。后三者总名义气体面积相同。固定障碍只用于暴露静态障碍模型与动态气泡的差异，不能作为产品气泡实现。实验时长为 12 个无量纲时间单位，不是 12 秒实物运动。

## 验证证据

- `python -m unittest discover -s tests -v`：33/33 通过，包括新增的 8 项气泡测试；覆盖浮升、名义面积、接触反作用、重力反转后材料身份、边界、步长收敛及周长能量导数。
- `python experiments/bubbles/fixtures.py`，随后 `python run.py bubbles`：Godot 4.7.2 / Vulkan / RX 7900 XTX，5 个场景各 1,000 步，0 failures。最大位置/形状分量误差 1.51252e-5，预设容差 2e-5；不可变字段按 float32 字节比较。详见 `bubble-gpu-validation.json`。
- `python run.py gpu`：原工程基线 1,000 tick 守恒回归 0 failures。它不验证新的气泡模型。
- `python experiments/bubbles/run_experiment.py`：输出完整释放曲线 CSV、状态 JSON 与材料/气体面积检查。`plot_results.py` 从实际状态绘图，不是预生成物理或预录动画。

## 必须保留的限制

本次 12 单位时间内曾通过检测线的颗粒数：无气泡 30、单气泡 24、双气泡 18、固定障碍 15；所有实验材料计数及名义气体面积检查通过。单气泡与双气泡的总面积相同，结果说明在此模型中气体分布会影响释放，不能外推为真实产品规律。对应图为 `bubble-release-curve.png` 和 `bubble-states.png`。

1. 没有求解液体不可压缩性、压力与回流；液体仅提供规定的浮力和阻力。不能把这种近似称为完整三相耦合。
2. 椭圆不能分裂、合并或自由改变拓扑，没有液膜排水、润湿与接触线模型。形状轴固定于坐标系，任意角度物理等价性尚未验证。
3. 接触采用软惩罚，并允许有限穿透。grain–bubble 的膨胀椭圆并非精确距离；报告的 penetration 是每 0.05 时间单位采样的 grain–grain / grain–bubble 近似量，未包含 bubble–bubble，不能称为全程最大穿透或严格无重叠。
4. 气体面积守恒是各椭圆面积之和恒定；若发生重叠，它不等于几何并集面积，也不证明真实气体体积/压力守恒。
5. 只有矩形实验槽、少量颗粒、单一初始排列。未验证圆形边界、大规模浓相、完整翻转循环、最终山脉或长期稳定性。
6. 首颗粒提前通过不等于整体释放更快。必须比较完整释放曲线；不能从一组实验推断空气量与释放速度普遍单调。

## 下一步与检查点

此候选模型可以作为数值对照，不应直接替换主程序。下一步需针对气泡层附近的液体回流、局部通道与接触床做统一实验，加入气体相互重叠监测和多方向/多初始条件测试，再决定保留椭圆近似或改用可变形界面。E1 稀相沉降、E2 气泡夹杂和 E3 高度场目前是不同尺度的实验，不能简单拼接并宣称完整物理。
