# 保守界面输运改进（2026-10-24）

## 本轮结果

新增共享限幅线性面重建（MUSCL）和 SSP RK2 时间推进，减少此前五材料输运的数值扩散。物理库存不裁剪、不归一化、不重采样；旋转继续演化同一状态。本轮仅修改独立 CPU 实验，未替换主程序，未新增表面张力。

每个 cell/方向对所有材料使用同一个限幅系数，保持各相重建斜率之和为零，因而公共载体速度分配后仍保持面总体积通量。局部上下界和出流 CFL 控制非负性；第二个 RK 阶段重新解压力并检查稳定步长，最多 16 次缩步重试，每次 advance 最多 128 个已接受子步。异常退出保留最后已接受状态及对应模拟时间。

发现并修复浮点边界问题：恰好落在限幅边界时可能产生约 1e-20 的负面值，导致空相虚假出流和趋零时间步。共享斜率系数现在保留 1e-14 相对余量，没有裁剪守恒 cell 数据。将来移植 float32 时需按精度重新选取数值余量和测试，不能直接照搬 float64 常数。

## 已执行验证

- `python -m unittest discover -s tests -v`：47/47 通过。新增面重建约束、解析平移精度/网格收敛、尖锐层有界性/库存以及圆形压力耦合旋转测试。
- `python tests/interface_validation.py`：64 cell 周期平移一整圈，正弦体积分数的平均绝对误差从 0.04224197 降至 0.00165266（约减少 96.1%）；方波从 0.19501821 降至 0.05235311（约减少 73.2%）。该隔离测试两种空间格式都使用 RK2，避免将时间格式差别算作空间精度提升。方波值域保持在 [0,1] 内，库存误差约 1e-16。这是已知解的数值输运测试，不是实物气泡验证。
- 平滑算例 32→64 cell 时新格式误差从 0.00541136 降至 0.00165266；没有据此承诺所有界面都有严格二阶收敛。
- `python experiments/liquid/run_experiment.py --scheme muscl`：圆形 24²、180 子步、9 个无量纲时间单位，4.5 后旋转 135°。最大材料库存误差 1.38778e-17，局部总体积误差 1.35879e-10，最小相分数为 0。结果见 `liquid-transport-muscl.json`。
- `interface-transport-comparison.png` 来自两种格式的实际状态；同初始条件、同旋转历史、同色标。完整实验对比包含空间和时间格式的共同变化，不能单独归因于其中一项。
- 已检查对照图：新格式保留了更多气相集中区域，但仍可见变形与扩散，不能据图判定真实气泡成立。
- 本轮重跑 `python run.py gpu` 与 `python run.py liquid`：原基线 1,000 tick 守恒和现有 4 组压力/面通量 GPU 对照均为 0 failures。shader 未修改；这些回归不覆盖新 CPU 输运的 GPU 移植。

## 未解决项

减少扩散不等于完整气液界面模型。仍无毛细压力跳跃、表面张力、润湿、液膜排水及沙床接触；相分数也不是带身份的离散沙粒。主程序仍是旧 GPU 工程基线。本轮新输运只有 CPU 验证，已有压力 GPU 测试不证明它能在 GPU 正确运行。

下一步需要验证毛细力的平衡离散（静态圆泡压差与伪流），再把压力、输运和颗粒接触统一到 GPU 求解器；保持有限迭代预算与守恒检查。不能仅用较清晰的浓度图宣称真实流沙画物理通过。
