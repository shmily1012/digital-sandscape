# 气相状态驱动的 GPU 浮力反馈

本轮将当前 GPU 气相体积分数接入压力右端：面驱动 `j = -M B g (c_a+c_b)/2`，其中 B=0.02 为无量纲实验密度差驱动强度，液体静水参考已扣除。随后求解封闭压力、生成无散面速度并保守输运界面。每步从上一步的界面重新计算源项，不使用预定运动轨迹。

这采用既有 Darcy/薄隙近似，不是完整惯性流体；没有标定实际玻璃间隙、液体黏度或矿物参数。当前也没有表面张力、颗粒接触或气泡漏沙，不能把浮升方向正确当作产品物理验收。

## 实机检查

Godot 4.7.2、Windows Vulkan Mobile、RX 7900 XTX，32² 封闭圆形域。同一份状态执行 20 步重力向下、20 步重力向上，每步请求 dt=0.02：

- 40 步均接受，CPU/GPU 最大体积分数差 6.378e-6。
- 最大气相面积误差 5.613e-10；圆外零状态，体积分数位于既有数值容差内。
- 每步独立检查气相质心沿重力反方向移动，包括重力反转后。
- 41 步外部驱动/失败恢复回归通过，66 项 CPU 测试通过，旧 GPU 1000 tick 守恒回归通过。

本验证中完整状态读回只用于测试；同一计算链的浮力、压力和界面更新之间无 CPU 读回。生产主设备接入与稳定性能测量仍未完成。误差阈值沿用输运测试 3e-4，没有为本次结果放宽。

## 运行

已有压力/几何基础 fixtures 后：

```powershell
python experiments/liquid/buoyancy_fixtures.py
python run.py buoyancy
```

原始证据：`reports/buoyancy-validation.json` 与 `reports/buoyancy.log`。
