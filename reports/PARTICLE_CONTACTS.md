原失败区间现用两个 0.025 子步完成，共三次尝试，elapsed=0.05，最大残差 9.15e-10。四个固定 0.0125 子步的终点与它最大相差 1.556e-4（坐标域宽度为 1）；这是时间离散敏感性的证据，不能宣称已时间收敛或轨迹唯一。

相同 16 颗粒实验现完成全部 240 步，沉积静止、重力反转移动、身份和边界验收均通过。CPU 总运行约 26 秒，不是实时性能。已重新查看状态图，仍是粗颗粒诊断图，艺术质量未达标。

新增失败输入重放、时间覆盖、部分子步成功后的整段回退和非法几何不重试测试；全套 **91 项 CPU 测试通过**。旧 GPU 1000 tick 回归通过；此接触模块仍没有 GPU 实现，没有液体/气泡耦合。

下一步先明确时间离散误差与平移摩擦的局限，推进接触 GPU 对照和液体反力接口，不能将独立接触与独立压力简单叠加后宣称双向耦合。

目标是补齐旧稀相模型遇到颗粒便拒绝的缺口。新增 CPU `experiments/deposition/contact_particles.py`，通过法向单边约束和切向有效 Coulomb 摩擦求接触反力，颗粒身份和当前位置连续保留。尚未接入 GPU 或主窗口。

参考：[Radjai 与 Richefeu 的接触动力学说明](https://citeseerx.ist.psu.edu/document?doi=27ba470b2937b241f16f89faace4732b5a9b8c5e&repid=rep1&type=pdf)讨论速度层面的互补接触条件与隐式步进。本实现独立编写，仅借鉴接触约束思想；不是该论文完整算法，也没有复制来源代码。

## 当前方程及边界

- 局部过阻尼迁移率为 `1/drag`，外力是重力减浮力；接触反力也通过该迁移率影响速度。
- 法向条件：`lambda_n >= 0`，`gap/dt + J_n v >= 0`，二者互补。
- 切向反力限制为 `abs(lambda_t) <= mu*lambda_n`，迭代投影使其反抗滑动；零相对速度时可以维持静摩擦。
- 每次遍历所有粒子对和静止平面，采用串行 Gauss-Seidel 更新，检查最终投影残差。预算耗尽不提交候选状态。
- 圆形边界暂以内接正多边形表示；这是保守几何近似，有棱边偏差。
- 初始微小负间隙保留在约束中进行误差修正，不能截成零使数值穿透逐步累积。

只有平移自由度，没有转动和力矩，摩擦是有效模型而非真实球粒滚动；不能用单颗粒倾斜阈值宣称材料安息角已标定。没有液体压力反力、润滑、孔隙排液或气泡作用。现有快速颗粒迁移率不能直接在近壁密集床中使用，后续耦合必须重新验证。
