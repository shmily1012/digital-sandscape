# GPU 曲率移植与动态毛细失败诊断

## 最新：有界邻域备用曲率，200 步通过

加入独立的 `curvature_extend.glsl` pass：仅对高度函数无法解析的混合格，在最近的 1 或 2 格环带寻找至少两个原始有效高度曲率；仅当极差不超过 `max(0.5, 0.25*abs(mean))` 时采用平均值。备用值不会成为其他格的供体，避免递归扩散到无界范围；无供体或供体冲突时仍拒绝。该范围和一致性条件是待继续验证的工程近似，不是适用于所有拓扑的数学保证。体积分数、库存、界面位置完全不被该 pass 修改。

算法思路参考 [Basilisk 的曲率方法说明](https://basilisk.fr/src/curvature.h)，其中介绍高度函数失效后的邻域平均及拟合。未复制其源代码或添加依赖；本项目 CPU/GLSL 独立实现了更受限的邻域延拓，没有声称实现完整 Basilisk 曲率算法。

本轮真实结果：

- 七组静态/捕获状态 CPU/GPU 对照通过，含原第 159 步输入；原始和备用曲率有效性均无差异，最大曲率差 8.06e-5。
- 200 步毛细/浮力/压力/界面反馈通过，中途反转重力；累计无量纲时间 0.1，最大体积分数差 3.324e-5，最大气相面积误差 1.124e-9。原第 159 步拒绝问题在此序列解决。
- 69 项 CPU 测试通过，包含供体冲突拒绝和禁止递归传播；旧 GPU 1000 tick 守恒回归通过。

当前检查没有覆盖近距离多气泡的错误跨界借值、壁面接触角、拓扑变化、长时间稳定、真实物性标定或颗粒释放。下一步需要把当前两相求解接入主设备可观察实验，并继续检查曲率备用比例、物理形变与成本，再连接颗粒。下方失败记录保留为历史，`capillary-feedback-validation.json` 已更新为本轮成功结果。

## 后续修复与更长验证

分类采用 1e-6 的近纯相范围：只有相邻样本同属近纯气相或近纯液相时，微小非单调不再被解释为第二个界面；条带高度仍积分原始体积分数，不裁剪状态。CPU 和 GLSL 同步修改，并增加近纯相噪声与明显第二界面测试。后者仍明确拒绝。没有放宽体积分数误差、守恒或动态步验收阈值。

原 40 步毛细测试完整通过，最大 CPU/GPU 误差 3.800e-6，面积误差 7.208e-10。六组 GPU 曲率对照通过，68 项 CPU 测试及旧 GPU 守恒回归通过。

进一步生成并运行 200 步参考：前 158 步成功，累计时间 0.079；第 159 步起拒绝，最终 126 项断言失败，最大参考差 0.00540237（参考继续演化而 GPU 保留状态）。该长序列当前仍失败，不能宣称修复完成。诊断捕获改为任意首次拒绝，已覆盖原第 7 步诊断文件。CPU 对新拒绝状态的曲率有效性与 GPU 一致，分数范围 [0,1]；多个面不可解析，包含 0.999998927 的近纯相尾迹及受条带判据影响的主界面格。仅继续增大容差不足以证明模型正确，下一步需要评估更稳健的局部界面重建/曲率估计。

延长测试：`python experiments/liquid/buoyancy_fixtures.py --capillary-steps 200` 完成后再运行 `python run.py capillary-feedback`。默认生成器仍为 40 步；必须明确报告实际步数。以下为早期失败历史。

新增 `curvature.glsl`：从当前体积分数计算三列、十一格高度函数曲率，每格输出曲率与有效性。新增毛细残余面力，与浮力一起生成压力右端；使用固定参考曲率 5 做压力分解，实际曲率仍来自当前状态，不重建圆泡。总压力需加回 `sigma * reference * c`；当前输出压力仅为残余压力。

## 未通过：持续毛细反馈

32² 圆泡、张力 0.001、浮力强度 0.02、dt=0.0005（低于实验毛细步长上限），预期 40 步。前 6 步成功，第 7 步因不可解析界面拒绝，后续仍拒绝，累计时间停在 0.003。测试退出码 1、102 个断言失败，包含接受状态、累计时间、方向和与继续演化 CPU 参考的差异；不是 102 个独立缺陷。尚未验证反向重力下的毛细演化。

读回第 7 步输入后，CPU 曲率也判定相同位置不可解析，有效性差异为零。问题面 617/618 与 618/650；格 618 的高度条带接近纯相部分存在 -5.96046e-8 的非单调变化，超过当前 -1e-8 判据。另一轴不满足纯相端点条件。分数本身在 [0,1] 内，说明仅有界和守恒不足以保证高度函数可解析。

尝试将单调判据设为两个 float32 ULP 仍在后续步骤失败，已撤回，未通过放宽测试标准隐藏问题。拒绝时体积分数和误差补偿保持不变。新毛细求解仍不适合产品运行；需改善近纯相曲率重建并验证较长演化、静态压差和伪流。
