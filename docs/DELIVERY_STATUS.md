## 当前默认实现

| 边界 | 当前代码与职责 |
|---|---|
| 应用入口 | sandscape.tscn → src/sandscape.gd → phase_preview.gd → main.gd |
| Physics Engine | PhaseFluid，气液相场/D2Q9与16颜色单粒能量交换；集体交换、混合浮升候选默认关闭 |
| Art Renderer | PhaseArt和glass shader，只读取状态；细腻度尚不满足最终视觉验收 |
| Aesthetic Director | AestheticDirector持有姿态；RotationRhythm只输出可选定时姿态意图，不识别沉降完成 |
| Adaptive Resource Manager | 五档请求预算、独立物理/渲染调度、帧时代理与有界积累；没有实际GPU利用率闭环 |
| 完整存档 | EnergyStateManager，独立双槽journal；60 bytes/cell快照加元数据，不等于运行总显存 |
| 平台边界 | OrnamentWindow仅改变应用窗口边框/置顶/位置；尚无壁纸和屏保宿主 |

正常绘制不整场读回；保存检查点会读回完整状态。旋转不初始化物理场。当前默认模型不是旧M1的单材料纹理/两个Margolus dispatch；旧0.5 MiB和旧吞吐指标不可套用当前模型。
