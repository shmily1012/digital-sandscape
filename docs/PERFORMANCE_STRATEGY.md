# 资源与性能策略

物理重审后的压力候选最新实测见 [多层压力报告](../reports/MULTIGRID_PRESSURE.md)：小网格仍有数毫秒压力成本，显式毛细子步另有约束。旧 M1 的低耗时不适用于新三相求解器。性能优化不能降低材料守恒与物理连续性要求。

## M1 已实现的边界
- 默认 256²，启动可选 512²/1024²；输出窗口独立缩放。
- 状态 R32_UINT + 展示 RGBA8，理论专用纹理内存分别 0.5/2/8 MiB，非实测总显存。
- 每 tick 两个 compute dispatch；只在状态更新后 colorize；画面可以复用上次纹理。
- 默认 30 Hz 物理、60 FPS 画面；失焦 5 Hz/10 FPS。Space 明确暂停。
- frame delta 只当代理，2 秒调节一次，10 秒稳定后探测恢复；先降低画面上限到 30，再在严重卡顿下降低物理到最低 15 Hz。没有 GPU 时间/利用率测量时 UI 显示 unmeasured。
- 单帧最多两 tick、delta 最大计入 0.1 秒，单个待处理 render-thread 包。恢复后不会无限补帧。模拟时间为 tick/30，降低频率时允许受控时间缩放。
- 正常路径没有 GPU→CPU 状态读回，不调用主 RenderingDevice.submit/sync。

## 测量矩阵
Windows Vulkan 与 macOS 可用 RD 后端分别跑 256、512、可选 1024；每种尺寸冷启动后预热 10 秒，观测 60 秒活动和静止阶段，记录显卡、驱动、后端、Godot、窗口尺寸、seed 和参数。分开记录 physics/colorize/draw 的 GPU timestamp p50/p95/max、CPU frametime、tick/s、FPS、显存和同时运行前台应用影响。长稳和电池/热约束单列；显卡型号不能替代测量。

降档顺序：装饰效果→渲染 FPS→视觉采样→流体迭代（未来）→物理频率。物理分辨率只在用户明确的新世界或经过验证的守恒迁移时调整。所有 GPU timestamp 异步读取，降档迟滞，质量切换不调用初始化。

## 未实现/未测
在线 GPU 时间与实际利用率、温度、电池、其它前台进程识别、遮挡状态和设备丢失恢复仍未实现。当前仅依据本窗口焦点，不把它当桌面可见性。已在 Godot 4.7.2 上完成 local RD 小基准：256² / 512² 单 tick+colorize p95 约 0.01036 / 0.02876 ms。范围不含 Canvas 绘制和应用整体开销，详见 reports/RUNTIME_VALIDATION.md；不能作为利用率或长期预算结论。

## 压力粗层融合与提前收敛扫描优化

GPU 排液算子新增原版 / 跳过已收敛扫描 / 粗层融合三条对照路径，各八例重复三次，共 72 次调用零失败。三路径最终 H、液流及压力证书逐字节一致，CPU oracle 阈值未放宽。保留输入非法、压力预算耗尽时整批拒绝。`multigrid_gpu.gd` 两项优化均为显式可选，其他调用者默认行为未切换。

`pressure_coarse.glsl` 将 4×4 最粗层的 32 次 Jacobi dispatch 合并为一个工作组内的 32 次迭代，用共享内存和统一 barrier；仍读取同一方程、使用同一松弛系数。存储输入输出使用独立缓冲区，并更新 parity。首个实现使用同一存储输入/输出，虽然粗层最终值相同，但下游结果失败；独立缓冲区后全部逐字节回归通过。未将这一观察归因于已证实的驱动缺陷。

残差 shader 的提前返回只用于同一 solve 的后续检查；每次 solve 的第一次检查无条件执行，避免复用上一轮收敛标记而跳过新 RHS。`python run.py adaptive-fused` 验证冷启动、相同 RHS、改变 RHS、预算不足、NaN 五例零失败；原 `adaptive` 五例也通过。共享 solver 没有新增 CPU 中途读回。

三次顺序采样中位 GPU 时间（ms）：单粒 11.443→4.826，接触双粒 17.650→9.035，64² 十六粒 31.322→21.956，零速度 9.963→3.854。仅跳过扫描收益较小；粗层融合减少每个预录 V-cycle 的 31 次 dispatch/barrier，是本轮主要收益。仍有 128 轮预录命令成本，且十六粒约 22 ms 远未证明产品资源预算达标。未控制温度/前台负载，不是稳定帧率 benchmark。

证据：`reports/drainage-chain-gpu.json`、`reports/drainage-fusion-comparison.json`、`reports/adaptive-pressure-fused.json`。本轮未推进颗粒、接触历史或气泡联动。下一步须减少剩余预录空转和几何全面遍历，再把 GPU 排液与接触历史接成有界共同提交；保持现有物理验收范围。
