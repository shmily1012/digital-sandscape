## 长周期发现（2026-10-25）

多气泡120000 tick和12个独立重放检查点通过完整性验证，但气泡与残留沙帽长期停在中部，后期轮廓不自然。下一项重点为气泡—沙帽共同运动与界面行为；不要继续用更多同类稳定性测试替代可见物理修复。

## 持久作品入口更新（2026-10-25）

`Digital Sandscape.cmd` / `python run.py sandscape`已支持完整会话保存恢复；旧Sandscape Preview仍为临时观察入口。下一步验证多气泡长周期沉降与翻转，再改善细腻渲染。气泡完整力学、平台集成和跨平台验证尚未完成。

## 当前可见作品（2026-10-25）

`Sandscape Preview.cmd` / `python run.py sandscape-preview` 是当前多气泡作品入口。已验证同一状态中的气泡区域9→7→6→5、局部漏沙与翻转连续性。该入口暂不存档；长周期、模型版本化存档、自然沙诱导分裂与精细渲染仍需继续。单泡实验保留为诊断，不代表完整体验。

## 当前入口更新（2026-10-25）

`python run.py bubble-demo` / `Bubble Demo.cmd` 可直接观察能量交换候选，临时作品不存档。上方留沙与两侧释放已有窗口证据，但接触载荷和自然沙诱导分裂未验收。下文M1环境安装步骤为历史计划，Godot4.7.2及本机Vulkan已验证，不需要重新安装。

# 分阶段交付计划

当前物理阻塞验收：气泡承载与沙粒反作用未实现。`python run.py phase-contact`
已复现下缘聚沙及频繁牵引限幅；守恒通过不等于承载通过。下一修改以
[承载验收](BUBBLE_CONTACT_ACCEPTANCE.md) 为准，暂不以渲染改善推进物理验收。

当前优先级：执行 [面向产品的交付恢复计划](DELIVERY_PLAN.md)。冻结独立求解器扩展，先在主应用完成旋转、释放、沉降、堆积的可见闭环。物理重审中的因果约束仍适用；局部实验通过不等于产品验收。

| 阶段 | 实施范围 | 验收出口 |
|---|---|---|
| M0 研究与架构 | 环境、仓库/许可证/维护检查、产品规格、风险、数据与线程设计 | 文档完整；Godot 与后端实机确认，若不可用则保留阻塞项 |
| M1 最小物理原型（本轮） | 密封圆、三沙类、GPU 守恒分块、鼠标旋转、持久会话、种子、基础资源边界 | CPU 不变量、GPU 差分、Windows 实机交互和堆积视觉通过 |
| M2 物理可信度 | 液体近似、功能气泡/漏流、滑坡与沉降参数、任意角度偏差修正 | 气泡确实影响释放；低方向偏差；多角度山谷/层次可见 |
| M3 艺术渲染 | 精细矿物、玻璃、自然阴影、视觉气泡、静止构图和欣赏期 | 对比截图与运动审阅；自然、无明显像素/闪烁；全由物理产生 |
| M4 自适应性能 | GPU 时间戳/benchmark、预算预设、可见性与电源策略 | 有实测证据；Focus 缓慢演化；质量切换不重置 |
| M5 产品功能 | 完整快照/恢复、自动翻转、摆件窗口、设置 | 部分沉降恢复一致；版本/校验和/原子存档；不打断欣赏期 |
| M6 平台集成 | Windows Lively、macOS 打包与导出路径、屏保、多屏 | 各平台实机长稳、签名/公证、休眠恢复、宿主管理生命周期 |

本轮不实施 M2–M6。M1 的分材料移动概率只是后续液体近似的基础。GPU 性能设计从 M1 开始，严格测量与预算 UI 在 M4，不能以未测试的功能清单替代验收。

M1 下一步：提供 Godot 路径 → 脚本解析 → CPU/GPU fixture 差分 → 交互旋转与关闭/重开 → 比较 256/512 视觉和 GPU 耗时 → 确认是否进入 M2。若 shader/API 不兼容先修复，再做新物理。
