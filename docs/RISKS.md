# 风险与验收缺口

更新：Godot 缺失、shader/线程/API 未运行两项已由 4.7.2 实测解决，见 reports/RUNTIME_VALIDATION.md。下表保留初始风险背景；macOS、自然山脉观感、长稳与完整预算仍未验证。

| 风险 | 证据/影响 | 处理 |
|---|---|---|
| Godot 不可用 | PATH 和已查目录无 exe；官方便携下载网络连接失败 | 等可用可执行路径；不得报告应用已运行 |
| shader/线程/API 未运行 | CPU 测试无法证明 Vulkan 和 RD 生命周期 | Godot 解析、GPU 差分、重复开关和窗口缩放 |
| 网格方向偏差 | 特定探针最大 11.418° | M2 改善方向采样与相位策略；多 seed/角度统计 |
| 液体流沙观感不足 | M1 无气泡/压力，仅沉降概率 | M2 功能气泡与漏流；M3 艺术审阅 |
| 种子不是完整存档 | M1 跨进程不恢复 | M5 版本化完整快照，保留 seed/tick/角度/气泡 |
| GPU 预算不可硬控 | 无可靠跨系统利用率 API | 分开目标/估计/实测，GPU 时间戳与代理分开 |
| macOS backend 不确定 | 未实机验证 | 先测试 storage formats/同步/导出；再平台集成 |
| 参考许可 | Powder-Sim API license=null；GPL 项目 | 不移植源码；采用接口集成与独立实现 |
| 长期重复性 | 1,000 tick 旋转只是守恒测试 | 后续测完整沉降循环的轮廓相似度，不承诺无限独特 |
| Lively 生命周期 | 文档对 application wallpaper 暂停有特殊限制 | 不能只依赖宿主自动暂停，M6 实测 IPC/可见性 |
