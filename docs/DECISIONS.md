# 技术决策记录

- ADR-010：撤回“先把空位减速当液体、后加气泡即可”的建模路线。先做沉降、接触成堆、气泡释放隔离实验；旧 2×2 保留工程对照，不作为物理正确性的证明。不在未验证时更换主 shader。

- ADR-009：用户提供 4.7.2 后以实际可运行的 4.7.2 为验证基线；GPU 70 tick 差分、1,000 tick 守恒和 256²/512² 主窗口测试通过。原 4.6.1 仍只代表最初选择。鼠标旋转采用事件坐标以支持稳定输入重放。

- ADR-001：固定 Godot 4.6.1 Standard 为可重复开发基线；不是声称本机已安装或它是最新版本。GDScript 无需 C#/.NET SDK。
- ADR-002：采用整数 R32_UINT + 独占 2×2 原地更新，避免多粒子争同一空位；本算法不需 ping-pong，使用显式相位 barrier。
- ADR-003：主 RD + Texture2DRD，共享 GPU 状态的显示投影，生产路径无每帧读回。测试用 local RD，允许 submit/sync。
- ADR-004：M1 只做有效沉降概率，绝不称为完整液体；功能气泡是 M2 的入口条件，而不是昂贵 CFD 的附属品。
- ADR-005：任意方向重力量化为 16 位幅值整数，保持连续控制并简化差分测试；网格运动误差单独测量。
- ADR-006：降频采用固定物理 tick 与显式慢时间，不在恢复时追赶全部墙钟时间。后台保持 5 Hz，符合 Focus 缓慢演化意图。
- ADR-007：M1 不建所有未来接口的空实现；输入保留薄宿主、存档与平台层在对应里程碑提取。
- ADR-008：参考项目只借鉴设计；Powder Toy/Lively GPL 源码不复制；Powder-Sim 未发现明确许可证，亦不复制。
