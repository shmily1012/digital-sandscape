# Digital Sandscape 产品规格

## 产品目标
Godot 4 Windows/macOS 生成式流沙画：黑、灰、白细沙在封闭圆形玻璃容器中缓慢沉降。体验以自然、安静、可长时间观看为核心，视觉参考真实 KB Collection 流沙画的层次与留白，不复制品牌资产。无积分、关卡、闪烁或游戏化像素风。

## 不可破坏的约束
- GPU Compute Shader 负责状态演化；渲染只读取物理结果。
- 旋转改变容器姿态和局部重力，不能清屏、补沙、重采样或重新生成山脉。
- 同一初始种子、算法版本和按 tick 记录的输入序列产生可复现状态；不以墙钟时间生成随机数。
- 黑白灰材料数量分别守恒，沙粒不得穿过圆形边界。
- Physics Engine、Art Renderer、Aesthetic Director、Adaptive Resource Manager 独立。
- 物理固定步长，渲染独立帧率；超预算降频或减慢模拟，不改变物理分辨率或丢弃粒子。

## 第一阶段范围
物理重审修订：以下为旧 M1 工程实现范围，不构成流沙画物理验收。功能气泡/局部释放与接触堆积必须经过独立实验，才能称为产品物理原型；不能再以“液体只需减速、气泡以后再加”为建模前提。见 PHYSICS_REASSESSMENT.md。

M1 默认 256×256 封闭圆形离散粒子场，可启动选择 512/1024；三种灰阶材料采用不同有效沉降概率；GPU 分块交换实现沉降与堆积；鼠标拖动与 0–360° 滑块控制；空格暂停；种子命令行参数；内存中持续物理状态；基础柔和边缘、玻璃暗部、细颗粒显示。资源管理器提供有界积累、每帧最多两 tick、后台 5 Hz 缓慢演化、帧时恶化时降频。状态及 tick 在旋转和缩放窗口时保留。

第一阶段不是液体/气泡仿真，也不承诺真实流沙画的长时间山脉形成。存档恢复、密度差、黏性、气泡漏流、桌面宿主和壁纸集成留到下一阶段。任意重力以连续向量输入，空间位移仍是离散近邻，需量化方向偏差。

## 验收
1. 在具备 RenderingDevice 的 Godot 4.7.2 环境打开即可运行；不支持 compute 时显示明确错误。4.6.1 是原规划版本，尚未实测。
2. 三材料计数在 1,000 tick 与角度变化后不变；圆外始终无沙。
3. 相同种子与 tick 输入重复运行得到相同原始状态；不同种子产生不同状态。
4. 重力向下、向上、向左、向右及非轴向输入使质心沿对应方向移动；零重力冻结。
5. 暂停、窗口尺寸变化和角度变化不能调用初始化。恢复使用原 tick。
6. CPU 参考测试、Godot 脚本检查、真实 GPU 测试分别报告，不能相互冒充。macOS 未实测就标记未验证。

## 资源目标（设计目标，不是实测结果）
默认画面 60 FPS、物理 30 tick/s，每 tick 两次分块更新。256² 专用状态+显示纹理约 0.5 MiB（不含 Godot/驱动/帧缓冲）。目标物理 GPU 时间 p95 < 2 ms；后续 GPU 时间戳实测后才宣称达标。普通运行不读回 GPU 状态；测试读回允许同步。

## 后续产品约束
Natural 默认；未来 Curated / Experimental 导演只影响物理允许的条件。运动应经过漏流、堆积、稳定和可配置的欣赏期，不能刚静止就翻转。平静体验是待用户反馈验证的产品假设，不作治疗承诺。长期新颖性通过多次完整沉降循环的轮廓相似度评估，不能用随机种子数量证明无限独特性。

功能气泡和视觉气泡分离，M2 先做浮升/阻挡/漏流，避免直接上昂贵流体。存档必须保存完整材料、气泡、tick、种子、参数、姿态和版本，而不仅是种子。未来支持 standalone、桌面摆件、Lively、screensaver 和可选创作导出；视频导出只能标为导出，不作为实时模拟替代品。
